## 一、设计方向

| 项 | 结论 |
|---|---|
| 风格层级 | 深色底 + 单主色 + 强对比点缀（tech-dark 变体） |
| 美学取向 | **东方夜水 · 极简仪式感**：大面积留白、克制的光、只有一处暖色冲击（纸签） |
| 情绪关键词 | 安静 / 缓慢 / 有期待 / 不喧哗 |
| 明确不做 | 紫渐变白底、彩色玻璃卡堆叠、发光按钮满屏、emoji 图标 |

**核心视觉冲突**：冷调深水（青绿 / 冰蓝）与暖调纸签（米黄 / 朱红）对撞。整个页面只有纸签是暖的、实的、不透明的，它因此天然成为视觉焦点。

## 二、Design Tokens

### 2.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--abyss` | `#04121c` | 页面最底层 |
| `--deep` | `#072330` | 水色中间层 |
| `--jade` | `#35e3b3` | 主色：选中态、粒子、倒计时微光 |
| `--cyan` | `#58c9ff` | 辅色：光束、渐变端点 |
| `--coral` | `#ff8f7a` | 点缀：第一尾锦鲤、S4 暖光 |
| `--gold` | `#f2d79b` | 仪式色：签筒入口、分隔线、印章外的金 |
| `--paper` | `#f6eedd` | 纸签底色 |
| `--ink` | `#16262a` | 纸签文字 |
| `--text` | `#e9f6f4` | 主文字 |
| `--sub` | `rgba(233,246,244,.56)` | 次级文字 |
| `--line` | `rgba(233,246,244,.14)` | 描边 |

主色家族共 3 组（青绿 / 冰蓝 / 珊瑚朱），其余靠透明度派生，不引入第四种颜色。

### 2.2 字体

| 用途 | 字体栈 | 说明 |
|---|---|---|
| 展示（标题、签头） | `"Songti SC","STSong","Noto Serif SC",serif` | 宋体给签文骨架感，Mac 自带 |
| 正文 | `"PingFang SC","Hiragino Sans GB","Helvetica Neue",sans-serif` | 干净、不抢戏 |
| 数字 | `"Avenir Next","Helvetica Neue",Helvetica,sans-serif` | 细体、宽字距、等宽数字 |

**字号阶**：`11 / 12.5 / 13.5 / 15.5 / 18 / 34 / clamp(38-58) / 40 / clamp(56-128)`
**字距**：中文标题 `.06em`，签头 `.2em`，全大写英文 `.3em`，单位小字 `.42em`

### 2.3 间距 / 圆角 / 阴影

- 间距基数 4px：`4 / 8 / 12 / 16 / 24 / 32 / 48`
- 圆角：胶囊 `999px`、纸签 `18px`、输入框 `10px`、印章 `6px`
- 阴影：纸签 `0 40px 80px -30px rgba(0,0,0,.8)`；主按钮 `0 14px 40px -16px rgba(53,227,179,.9)`；其余一律不用重阴影

### 2.4 动效

| 场景 | 参数 |
|---|---|
| 页面入场编排 | 标题 0ms → 说明 90ms → 胶囊 180ms → 日期 250ms → 按钮 320ms，位移 16px + 淡入，`cubic-bezier(.2,.8,.2,1)` 700ms |
| 锦鲤游动 | 限角速度转向（1.15 rad/s，转弯半径自然）+ 22 点中轴链式跟随 + 绘制期 S 形波动（尾端振幅 0.62×体宽），巡航 46~56px/s，摆尾频率随速度浮动 |
| 尾鳍 / 鳍叶 | 两片分叉叶片沿尾柄两侧长出，鳍条放射；胸鳍约 90°、腹鳍约 107° 的后掠角，摆动相位错开 |
| 签筒呼吸 | 外圈光晕 3.4s 无限循环，仅改变透明度与 2% 缩放 |
| 卡背晃动 | 1.15s，`rotateZ` 在 -2.6°~2.2° 之间衰减 |
| 翻面 | `rotateY 180°`，900ms，`cubic-bezier(.2,.75,.2,1)`，带 1.6° 初始倾斜 |
| 数字跳变 | 秒位变化时 8px 上移 + 淡入，400ms |
| 归零转场 | 冷暖叠层透明度 1.2s 过渡，光点 1.6s 爆散 |

**降级**：`prefers-reduced-motion` 下关闭锦鲤游动、光束漂移与入场位移，只保留透明度变化。

## 三、版式与层结构

### 3.1 五层（自下而上）

| 层 | 实现 | z-index |
|---|---|---|
| L1 底色 | CSS 渐变 + 3 个模糊色块（`blur(70px)`，26s 漂移） | 0 |
| L2 光束 | 3 条 `blur(24px)` 斜向渐变条，22s 缓动 | 1 |
| L3 粒子 | Canvas `#dustCanvas`，70 个柔光点缓慢上浮 | 2 |
| L4 锦鲤 | Canvas `#koiCanvas`，2 尾主体 + 12 尾虚化小鱼 | 3 |
| L5 内容 | 品牌栏 / 主内容 / 签筒 / 弹层 | 10+ |

另有一层 `#warm`（暖金渐变，默认 `opacity:0`），仅在 S4 淡入。

### 3.2 桌面端栅格

- 主内容：单列居中，最大宽度 660px（引导态）/ 自适应（倒计时态）
- 顶部栏：`padding: 26px 36px`，品牌左、操作右
- 左侧竖排装饰文字：`writing-mode: vertical-rl`，距左边 28px，`< 900px` 隐藏
- 倒计时：四段等宽（`min-width: clamp(64px,9vw,120px)`），段间 1px 金色竖线，竖线高度随视口缩放

### 3.3 移动端（≤720px）

- 倒计时改 2×2 网格，竖线隐藏，数字 `clamp(48px,16vw,74px)`
- 签筒入口改为底部固定胶囊，距底部 `22px + env(safe-area-inset-bottom)`
- 纸签：宽 `min(90vw,380px)`、高 `min(78vh,560px)`，签面内边距 `16px 14px`，签头 26px；内容超出时在签面内滚动（隐藏滚动条）
- 左侧竖排文字与底部提示隐藏

### 3.4 尺寸兜底（本次新增）

| 视口条件 | 处理 |
|---|---|
| 高 ≤700px（短屏笔记本 / 小屏手机） | 卡片高度改 `min(100dvh - 170px, 600px)`，保证翻面后「宜/忌 + 按钮行」不被挤出屏幕；签面各区块同步紧凑 |
| 高 ≤520px 且横屏 | 倒计时回到单行 4 段，数字 `clamp(34px,11vh,58px)`，卡片 `min(72vw,360px) × min(78vh,340px)`，签筒不再固定底部 |
| 视口抖动（移动端地址栏收放） | 画布重设 DPR，但宽变化 ≤80px 且高变化 ≤120px 时不重建鱼群，避免鱼瞬移 |
| 锦鲤尺寸 | `sc = clamp(0.48, min(W/1200, H/900), 1)`：桌面体长约 210px，手机约 100px，不出现「鱼比字大」 |

## 六、内容规格

### 6.1 签池（36 签）

| 签等 | 数量 | 视觉 |
|---|---|---|
| 上上 | 6 | 印章「上上」，朱红 |
| 上 | 12 | 印章「上」，朱红 |
| 中 | 18 | 印章「中」，朱红（描边减淡） |

每签字段：

| 字段 | 含义 | 呈现位置 |
|---|---|---|
| `tier` | 签等（上上 / 上 / 中） | 右上印章 + 签头下方小字 |
| `title` | 四字签头 | 签面主标题 |
| `verse` | 两行吉语（`\n` 分隔） | 签头下方，宋体行距 1.95 |
| `read` | 解签：白话解读 26~42 字 | 「解签」标签块，左对齐 |
| `good` / `bad` | 宜 / 忌 | 两行圆形字符引导，左对齐 |
| `color` / `colorHex` | 幸运色名 + 色值 | 幸运行：色点 + 色名 |
| `luck` | 幸运数字（由签号推导：`((no)×7 % 9)+1`） | 幸运行：数字 |
| `tip` | 今日小贴士 10~18 字 | 虚线分隔后的「今日一句」 |

签面版式分 4 组，用 `justify-content:space-between` 撑满卡面（不再靠 `margin-top:auto` 把页脚推到底，避免中段出现大片空白）：

| 组 | 内容 | 版式要点 |
|---|---|---|
| 签头组 | 页眉（锦鲤签 / 第 N 签）→ 印章 → 签头 → 签等 → 吉语 | 居中；页眉右侧留 54px 给印章，避免压字 |
| 解读组 | 金色分隔线 → 「解 签」标签 → 解读段落 → 宜 / 忌 | 标签独立成行、左对齐；解读做成引文块（左侧 2px 金线 + 4% 金底 + 右圆角） |
| 幸运组 | 幸运色 / 幸运数字 → 虚线 → 今日一句 | 幸运行居中、字距放宽；今日贴士以上为虚线分隔 |
| 页脚 | 今天，也是一条锦鲤 | 居中小字，紧跟幸运组，不吸底 |

### 6.2 选签算法

```
seed = FNV-1a("YYYY-MM-DD")  →  index = seed % 36
```

同一天所有人得到同一签，跨日自动更换。

### 6.3 导出图规格

- 尺寸 1080×1440（3:4），PNG
- 构成：深水渐变底 + 三处光晕 → 顶部品牌「锦鲤签 / KOI FORTUNE」→ 右上角半透明锦鲤剪影（金色→青绿渐变，52% 透明度，画在纸签之后，避免被纸签遮住）→ 中央米黄纸签区块（100,180,880,1120，含双线内框与竖向纤维）→ 页眉「第 N 签」与印章 → 签头（字距 28）→ 签等小字 → 吉语两行 → 金色分隔线 → 解签（逐字换行，最多 2 行）→ 宜 / 忌圆点行 → 幸运行（色点 + 色名 + 数字）→ 虚线 + 「今日一句」→ 页脚「今天，也是一条锦鲤」→ 底部日期与「每 日 一 签 · 好 运 常 在」
- 文件名：`锦鲤签-YYYY-MM-DD.png`

## 七、可访问性

- 所有按钮为原生 `<button>`，带 `aria-label`；弹层打开时焦点移入「收下」
- 文字与背景对比度：正文 ≥ 7:1（`#e9f6f4` on `#04121c`），纸签文字 ≥ 10:1
- 键盘：`Esc` 关闭弹层
- `prefers-reduced-motion` 降级见 §2.4
