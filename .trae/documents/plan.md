## 一、需求描述

### 1.1 背景

Trae Demowall 抽中三个命题关键词：**锦鲤**（主题词）、**倒计时器**（功能词）、**渐变梦幻风**（风格词）。需要在现场演示场景下，用一个作品把三者串成完整体验，并且能在 30 秒内让人看懂「它是什么、它好在哪」。

已确认方向为 **B · 好运签语倒计时**（见 `project_memory.md` §4）。

### 1.2 一句话定义

> **给一个你正在等的日子倒数，每天从一条锦鲤那里领一句签。**

用户打开页面 → 自己选一个重要日子 → 页面变成一片深水渐变，锦鲤在数字背后游动 → 底部一枚金色签筒，点开翻出一张米黄纸签，上面是今天的四字签头、一句吉语和宜忌 → 可以存成图片发出去。

### 1.3 目标

1. **命题达成**：三个关键词在首屏同时成立，不是「先看锦鲤再看倒计时」的割裂感。
2. **仪式感**：倒计时不是干巴巴的数字，而是「为某件重要的事倒数 + 每天领一张好运签」的日常仪式。
3. **开箱即用**：双击 HTML 即可运行，断网可演示，不依赖任何外部资源。
4. **分享欲**：签文可导出为图片，便于现场发群/发朋友圈传播。

### 1.4 范围

**做什么**

- 全屏渐变梦幻风背景：深水色底 + 多层流动光晕 + 缓慢上浮的柔光粒子 + 细微胶片颗粒。
- Canvas 程序化锦鲤：2 条主体锦鲤（一尾白底朱红、一尾墨底描金）+ 远景虚化小鱼群；游动有摆尾与路径跟随，鼠标靠近会躲开。
- 目标日设定：快捷日期（明天零点 / 一周后 / 一个月后 / 2027 元旦 / 2027 春节）+ 自定义日期，写入 `localStorage`。**首次进入必须由用户自己选，不提供默认日期**；未设置前只显示引导界面，不出现空倒计时。
- 大号倒计时：天 / 时 / 分 / 秒四段，超大号细体数字，单位小字在数字下方，数字变化有轻微纵向位移。
- 每日锦鲤签：日期作为种子 → 确定性抽签，签池 36 签（上上 6 / 上 12 / 中 18），每签含「签等 + 四字签头 + 一句吉语 + 宜 / 忌」。
- 抽签交互：点签筒 → 锦鲤向中央聚拢 → 卡背左右轻晃 → 3D 翻面出签 → 签文分两段浮现；同日再抽内容不变，只重播动画。
- 签图导出：点击「存为锦鲤图」，用 Canvas 手绘生成 1080×1440 PNG 并下载，含签文、日期与锦鲤剪影。
- 归零庆祝态：倒数归零时，画面转暖金、锦鲤跃出、光点爆开，文案切换为「此刻已至」。

**不做什么**

- 不做账号、不做服务端、不做数据上报、不做分享链接。
- 不做多语言、不做主题切换、不做历史签文回顾。
- 不做音效。
- 不做 App / 小程序形态，只保证响应式网页可用。

### 1.5 屏幕构成与线框图

### 1.6 逐状态交互说明

状态机共 5 态：`引导态 → 倒计时态 → 抽签中 → 签文态 → 庆祝态`，其中「抽签中」是过场态，不可停留。

---

#### S0 · 引导态（首次进入）

| 项 | 内容 |
|---|---|
| **看到什么** | 背景锦鲤照常游动；左侧大字「你在等哪一天？」；一行说明；5 个快捷日期胶囊；一个自定义日期框；一个主按钮「开始倒数」。中央**没有**任何数字。 |
| **能点什么** | ① 任意快捷日期胶囊 ② 日期框（唤起系统日期选择器）③「开始倒数」按钮（未选日期时置灰） |
| **点了发生什么** | ① 胶囊选中高亮（青绿描边 + 微光），日期框自动填入对应日期 ② 选中日期后主按钮激活 ③ 点「开始倒数」→ 整块引导内容淡出上移，倒计时数字从下方浮现（约 700ms 的入场编排）→ 进入 S1 |
| **退出条件** | 选定日期并点击「开始倒数」 |

#### S1 · 倒计时态（主场景）

| 项 | 内容 |
|---|---|
| **看到什么** | 顶部一行小字「距离 2027 元旦」；中央四段大数字（天/时/分/秒），数字下方是单位小字；数字下面一行「2027.01.01 · 还有 268 天」；底部一枚金色描边胶囊「抽今日锦鲤签」，外圈有一层呼吸光晕。锦鲤在数字后方缓慢横穿。 |
| **能点什么** | ① 抽签入口 ② 右上角「重设目标」 |
| **点了发生什么** | ① 数字每秒静静跳动，仅秒位变化；个位切换时向上位移 8px 淡入。② 鼠标移到锦鲤附近（约 150px 内），锦鲤改向避开，移开后恢复漫游。③ 点签筒 → 进入 S2。④ 点「重设目标」→ 回到 S0，日期框保留原值。 |
| **退出条件** | 抽签 → S2；重设 → S0；倒计时归零 → S4 |

#### S2 · 抽签中（过场，不可停留）

| 项 | 内容 |
|---|---|
| **看到什么** | 背景整体压暗并模糊；中央浮出一张卡背——深色玻璃质感、金色细边、中央一枚锦鲤线稿浮雕、底部「今日 · 十月廿四」。卡片开始左右轻晃。同时两条锦鲤从画面边缘向卡片方向聚拢。 |
| **能点什么** | 不可操作（整个过程约 2 秒，无按钮） |
| **点了发生什么** | 晃动约 1.2 秒后，卡片绕 Y 轴翻面（约 0.8 秒），米黄纸签正面出现 → 进入 S3 |
| **退出条件** | 动画结束自动进入 S3 |

#### S3 · 签文态

| 项 | 内容 |
|---|---|
| **看到什么** | 一张米黄纸签，带细小纤维纹理与轻微倾斜（约 2°）。左上「锦鲤签」与「第 21 签」，右上朱红方印（上上 / 上 / 中）。中央四字签头（大号宋体、宽字距），下面两行白话吉语。一条金色细线分隔，下接「宜 / 忌」。最底部「今天，也是一条锦鲤」。 |
| **能点什么** | ①「存为锦鲤图」②「收下」③ 点卡片外空白处 |
| **点了发生什么** | ① 生成 1080×1440 图片并触发下载，按钮短暂变为「已存下」②/③ 弹层淡出，回到 S1；签筒按钮变为「今日签 · 上上」（表示今天已领，但仍可重新打开查看，内容不变） |
| **退出条件** | 关闭弹层回到 S1 |

#### S4 · 庆祝态（倒计时归零）

| 项 | 内容 |
|---|---|
| **看到什么** | 背景由冷调水色转为暖金，光点从画面中心爆开；中央文字变为「此刻已至」+ 一行「你等到的那一天，到了。」；锦鲤从底部向上跃出画面。 |
| **能点什么** | ①「把这一刻存下来」（存一张庆祝版签图）②「再定一个日子」 |
| **点了发生什么** | ① 触发与 S3 相同的导出流程 ② 回到 S0 引导态 |
| **退出条件** | 重新定日子 → S0 |

### 1.8 验收标准

| 编号 | 验收项 | 判定标准 |
|---|---|---|
| A1 | 离线可用 | 断网双击打开，无 Console 报错，全部功能可用 |
| A2 | 命题可见 | 首屏 3 秒内可同时识别锦鲤、倒计时、渐变梦幻风三个元素 |
| A3 | 状态可达 | S0→S1→S2→S3→S1 全链路可走通，无死角状态 |
| A4 | 倒计时准确 | 与系统时间误差 ≤ 1 秒/分钟，跨天自动进位 |
| A5 | 目标日持久化 | 设置后刷新页面仍保留；未设置时只出现 S0，不出现空倒计时或 00:00:00 |
| A6 | 签文确定性 | 同一日期多次打开签文一致；日期变化后签文变化 |
| A7 | 交互完整 | 抽签 → 翻卡 → 收下 → 导出图片全链路可完成 |
| A8 | 响应式 | 1440×900 与 375×812 两种视口下无溢出、无遮挡、可操作 |
| A9 | 性能 | 桌面端动画稳定 ≥ 50 FPS，长时间运行无内存持续增长 |

## 二、执行计划

### 2.1 功能拆解与开发顺序

按「先骨架、后血肉、再打磨」排布，每一步都能独立验证：

| 序号 | 任务 | 关键内容 | 依赖 |
|---|---|---|---|
| T1 | 页面骨架与五层结构 | L1~L5 分层 DOM；CSS 变量定义色板；顶部品牌栏与主内容容器 | — |
| T2 | S0 引导态 | 快捷日期胶囊、日期框、按钮激活逻辑、入场编排 | T1 |
| T3 | 倒计时引擎与 S1 | 每秒重算、天时分秒拆分、数字位移过渡、`localStorage` 读写 | T2 |
| T4 | 渐变梦幻背景（L1/L2/L3） | 多层径向渐变动画、斜向光束漂移、上浮粒子 Canvas、颗粒纹理 | T1 |
| T5 | Canvas 锦鲤（L4） | 鱼体曲线建模、摆尾、路径跟随、鼠标避让、远景虚化鱼群 | T1 |
| T6 | 每日签与 S2/S3 | 日期哈希选签、36 签文案、卡背/翻面/签文排版、当日不变逻辑 | T1 |
| T7 | 签图导出 | 1080×1440 离屏 Canvas 版式绘制与下载 | T5, T6 |
| T8 | S4 庆祝态 | 归零检测、冷暖色调切换、光点爆发、锦鲤跃出 | T3, T5 |
| T9 | 响应式与打磨 | 375 断点布局、触控事件、`prefers-reduced-motion` 降级、性能排查 | T1~T8 |

**里程碑**

- **M1 能跑**（T1 + T2 + T3）：S0 能选日期，S1 能准确倒数。
- **M2 好看**（T4 + T5 + T6）：背景、锦鲤、翻卡视觉成立，S2/S3 可走通。
- **M3 能秀**（T7 + T8 + T9）：可导出、有高潮、适配现场设备。

### 2.2 关键技术决策（细节留待设计阶段）

| 议题 | 方案 | 理由 |
|---|---|---|
| 动画实现 | Canvas 2D 分层：粒子层与锦鲤层各自一块画布 | 比 DOM/SVG 稳，锦鲤与粒子互不干扰 |
| 锦鲤建模 | 中轴线取点 → 法线偏移出轮廓 → 曲线平滑填充；尾鳍为三段飘带 | 纯代码可控色相，贴合渐变梦幻风，零素材 |
| 抽签随机 | 日期字符串 → FNV-1a 哈希 → 取模 | 纯前端可复现，保证「同日同签」 |
| 导出图片 | 手绘 Canvas，不引入 html2canvas | 零依赖，规避跨域与字体问题 |
| 字体 | 展示用宋体（`Songti SC`），正文用苹方，数字用细体无衬线 | Mac 现场环境自带，零加载 |

### 2.3 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| Canvas 锦鲤动画掉帧 | 现场演示卡顿，质感崩塌 | 粒子与鱼分离为两块画布；`devicePixelRatio` 上限 2；鱼数量固定为 2 |
| 中文字体在导出图里渲染异常 | 分享图糊掉 | 导出使用系统字体 + 手动排版，不依赖外部字体文件 |
| 移动端小屏信息拥挤 | 若用手机演示会翻车 | 以 375 宽为第一优先级设计纵向堆叠，桌面端再扩展 |
| 首屏元素过多导致「看不出是什么」 | Demo 讲解成本高 | 主视觉中心固定为倒计时，锦鲤只做背景动效；抽签入口唯一 |
| 现场演示机时间/时区异常 | 签文与倒计时错乱 | 统一使用本地时间；每秒重算而非累加，避免漂移 |
| 首次强制引导多一步操作 | 现场节奏被拖慢 | 引导内容本身即第一屏，快捷胶囊一键选定，全程 ≤ 2 次点击 |
