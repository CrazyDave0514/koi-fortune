## 一、创作故事

### 为什么做这个项目

这个作品的起点，是三个抽中的关键词：**锦鲤、倒计时器、渐变梦幻风**。

拿到命题的第一反应是做加法——画一条会游的锦鲤，配一个能走的倒计时，再铺一层梦幻渐变，三个元素各就各位，任务完成。但这样的东西只能"被看见"，不能被"用起来"：锦鲤是背景板，倒计时是仪表盘，两者互不相干。

真正让它们连起来的，是一个很朴素的词：**等**。

倒计时，本质是在等一件事；锦鲤，本质是在等一点好运。所有倒计时的用户，都在经历同一段状态——事情还没发生，日子还得一天一天过。而市面上大多数倒计时工具，对这段过程是冷漠的：数字越大，压迫感越强；打开一次，关掉，第二天再打开，数字又少了一点，除此之外什么都没有。

我们想补上的，就是"除此之外"。

所以《锦鲤签》做的不是"倒计时 + 抽签"的功能拼盘，而是一个**关于等待的日常仪式**：你先告诉自己，你在等哪一天；从那天起，页面变成一片深水，锦鲤在数字背后慢慢游；你每天可以点一次签筒，领一张当天的签——四字签头、一句白话吉语、宜与忌。它不催你，也不打分，只是每天给你一句"今天可以怎么过"。

锦鲤在这里不是招财符号，而是一个陪跑的角色。倒计时也不再是压力表，而是一份"还有多少天可以慢慢来"的提醒。

### 它解决了什么具体问题

**1. 等待期的"无反馈"，被一条每日签填上了。**
备考、等 offer、等放榜、等一个异地的人回来——这些等待最长、最难受的部分不在终点，而在中间那些没有任何回音的普通日子。每天一张签，是成本极低的一次正反馈：打开就有，不用登录，不用坚持，不用打卡。

**2. 抽签类产品的"无限刷新焦虑"，被日期种子解掉了。**
常见的好运类应用鼓励你一直抽，抽到满意为止，本质是让人对随机上瘾。《锦鲤签》用当天日期做哈希种子：**同一天，所有人打开都是同一签；过了零点，自动换签**。它不给你"再抽一次"的按钮，因为今天这句就是今天这句——这个约束反而让签文有了分量。

**3. 好运类内容"看完即走"，被一张可保存的签图接住了。**
签文不是弹窗文字，而是一张米黄纸签：签等方印、宋体签头、宜忌两行。它可以被导出成 1080×1440 的图片，直接发群、发朋友圈、发给那个和你一起等的人。仪式感需要一个可以留下的物证，分享欲也需要一个不费力的出口。

**4. 演示与使用的门槛，被"单文件离线"压到了最低。**
整个作品是一个 HTML 文件，原生 HTML/CSS/JS，零依赖、零构建、零网络请求，断网双击即可运行。现场大屏能演示，自己电脑上也能一直开着当背景——不需要装任何东西，也不会因为网络或账号卡住。

### 一句话版本

> 不是帮你更快地熬到那一天，而是让等待的每一天，都值得打开一次。

## 二、使用场景

### 场景 1｜长线等待：备考、求职、等一个结果

- **谁**：考研 / 考公 / 考证的人，投完简历等回音的人，等放榜、等体检、等签约的人。
- **怎么用**：首次进入选「考试日 / 放榜日 / 自定义日期」，之后每天打开一次，看一眼还剩多少天，抽一张当天的签。
- **得到什么**：把"还有 87 天"这种抽象压力，拆成"今天还剩一天要做的事"。签文里的宜 / 忌，往往正好是一句能落地的小提醒（宜投递、宜开口、忌反复自我怀疑）。

### 场景 2｜节点倒数：跨年、生日、纪念日

- **谁**：想给新年、生日、在一起的第 N 天做点仪式感的人。
- **怎么用**：用「2027 元旦」「2027 春节」这类快捷胶囊一键设定；当天抽签后点「存为锦鲤图」，把签面导成图片。
- **得到什么**：一张可以直接发出去的节日图，既有具体的倒计时，又有一句只属于这一天的吉语。零点之后打开是同一张签，群里几个人发的图能对上——天然适合当"新年暗号"。

### 场景 3｜相聚之前：异地见面、旅行出发、婚礼筹备

- **谁**：异地恋、约好一起旅行的人、正在筹备婚礼或搬家的人。
- **怎么用**：设「一周后」「一个月后」或具体出发日；偶尔把签图发给对方，代替一句"还有 XX 天"。
- **得到什么**：把等待变成双方共享的进度。一个人倒数容易焦虑，两个人对着同一张签倒数，等待本身就成了一件有点甜的事。

### 场景 4｜现场演示与展会展示

- **谁**：作品展、Demo Day、朋友聚会上的分享者。
- **怎么用**：双击 HTML 打开，投到大屏；先选一个近在眼前的日期（如"明天零点"），让倒计时立刻有数；再点签筒翻一张签，展示签文与导出。
- **得到什么**：全程不需要网络、不需要登录、不需要讲解铺垫。观众在 30 秒内能同时看到锦鲤、倒计时和渐变梦幻风三件事，也能亲手抽一张。

### 场景 5｜桌面常驻：一个不打扰的背景

- **谁**：长时间对着电脑、希望屏幕上有一点活物和一点好兆头的人。
- **怎么用**：把页面常开在一个标签页或独立窗口，锦鲤在数字背后缓慢游动，鼠标靠近会绕开。
- **得到什么**：一个低干扰的视觉陪伴。没有音效、没有弹窗、没有推送，不会打断工作，只在你主动看过去的时候给一点反馈。

### 不适合的场景（边界说明）

- 需要毫秒级精度或多人协同的赛事计时、项目排期——它只是个轻量的个人倒计时，不承担工具职责。
- 需要长期数据统计、历史签文回顾、成就体系的需求——本版本明确不做账号与云端，数据只存在本地。
